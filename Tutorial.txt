2. FOLDER 1: AttendEase (Mobile Application)
================================================================================
Path: F:\Project 1\AttendEase

This is the primary repository containing the React + Capacitor mobile client. It builds 
into both a fully responsive Web application and a native Android app (.apk).

Key Modules:
------------
* src/screens/: Core screens (Dashboard, Timetable, LeaveManager, BunkCalc, Reports, Settings, Profile).
* src/hooks/usePermissions.js: System prompt controllers that request background and alarm notification permissions on application startup.
* src/utils/notificationsEngine.js: Internal scheduling logic for daily alarm notifications, weekend sleep checkers, and bedtime timetables.
* src/components/settings/PDFViewModal.jsx: Custom local file viewer that reads native folders (Documents/AttendEase/PDF), lets the user open them in Chrome/native PDF viewers, or clean them up.
* android/: Native Android project folder containing resources, Gradle wrappers, and Java setup assets.

App Lifecycle Adjustments:
-------------------------
* The onboarding workflow is: Sign In -> Setup Profile -> Add Subjects.
* Trial claiming: Claims are validated directly against Cloud Firestore to prevent trial loops. Once claimed, the button in Profile is permanently hidden.
* Navigation: Instantly preloaded (static imports in App.jsx) to facilitate smooth transitions.

3. FOLDER 2: attendease-webhook-WebSite (Payment Backend)
================================================================================
Path: F:\Project 1\attendease-webhook-WebSite

A lightweight Node.js Express server running on Render that bridges the client 
app and the Cashfree payment gateway safely. It handles credentials securely without 
exposing secret tokens on client screens.

Key Files:
----------
* index.js: Contains the Express endpoints.
  - POST /create-order: Initializes order sessions with Cashfree and saves a "pending" invoice log to Cloud Firestore.
  - POST /verify-payment: Webhook callback target that receives Cashfree IPN verification calls, confirms the payload, sets the user's "pro" state to true, and logs order status.
* serviceAccount.json: Secure key used by firebase-admin SDK to write subscription logs directly into the production Firestore database.
* .env: Stores environment API keys (`CASHFREE_APP_ID`, `CASHFREE_SECRET_KEY`).

Performance Optimizations:
--------------------------
* Client apps send warm-up fetches (`method: OPTIONS`) to this server when the user opens payment modals. This wakes up the Render container instantly, removing start-up lag for checkouts.

5. INTEGRATED ARCHITECTURE & FLOW
================================================================================

How checkout and pro activation works:
--------------------------------------
1. User in AttendEase clicks "Upgrade to Pro" -> Modal sends a warm-up ping to Render.
2. User selects plan -> Requests `attendease-webhook` `/create-order` endpoint.
3. Webhook requests Cashfree PG -> Returns a session ID. Webhook registers "pending" state in Firestore.
4. Client opens the secure Cashfree checkout page in the native browser.
5. User completes payment -> Cashfree sends confirmation to `attendease-webhook`.
6. Webhook verifies the payload, updates User Profile in Firestore: `{ pro: true, plan: "yearly", ... }` and adds a success payment log.
7. Mobile Client automatically synchronizes the new Firestore document state via live listeners, immediately unlocking premium tools (Leave Manager, Bunk Calculator, and PDF Exports).

7. STEP-BY-STEP DEVELOPER COMMANDS
================================================================================

Double-check you are in the correct directory in your terminal before running commands.

---
A. DEVELOPING & RUNNING ATTENDEASE (MOBILE CLIENT)
---
1. Install dependencies:
   cd "F:\Project 1\AttendEase"
   npm install

2. Run local web server:
   npm run dev

3. Compile web assets & Synchronize to Android native:
   npm run sync
   (This builds the React app into dist/ and copies it to the Android asset folders)

4. Compile Android Debug APK from Command Line:
   $env:JAVA_HOME="D:\Ai Software\AndroidStudio\Andorid Stuio\jbr"
   cd android
   .\gradlew.bat assembleDebug
   (APK compiles to: F:\Project 1\AttendEase\android\app\build\outputs\apk\debug\app-debug.apk)

5. Deploy Web version to Vercel:
   npx vercel deploy --prod --yes

---
B. RUNNING THE WEBHOOK BACKEND
---
1. Install dependencies:
   cd "F:\Project 1\attendease-webhook-WebSite"
   npm install

2. Configure environment:
   Create a .env file (copying from .env.example) and add your keys.

3. Run server locally:
   npm start

---
C. RUNNING & DEPLOYING HANKSTUDIO WEB PAGE
---
1. Setup Firebase Tools globally (first-time only):
   npm install -g firebase-tools

2. Log in to Firebase Account:
   firebase login

3. Deploy website & admin panels:
   cd "F:\Project 1\HankStudio-WebPage"
   firebase deploy
